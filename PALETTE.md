# kage palette

Generated by `nvim -l scripts/gen.lua` from `lua/kage/palette.lua`. Do not edit by hand.

Two variants: **kage shadow** (dark) and **kage dawn** (light). Copy any value into another app; ready-made configs for foot, ghostty, kitty, alacritty, wezterm, fzf, the kage TUI and CSS are under `extras/`.
